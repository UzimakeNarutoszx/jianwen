# 文章详情页

### 页面目标

把一条政策或新闻讲清楚，并允许用户继续追问。

### 信息顺序

1. 标题
2. 来源标签
3. 三句话总结
4. 正文
5. 继续问问
6. 来源与依据

### 标题区示例

```text
刚毕业找工作，最近有哪些政策可能用得上？

就业 · 约4分钟 · AI辅助整理
人社部 / 中国政府网 / 公开政策文件
```

### 三句话总结

模块名：

```text
先看这三句
```

示例：

```text
1. 这次重点是扩大就业服务、见习岗位和职业培训。
2. 对毕业生来说，最值得关注的是补贴、基层岗位和求职服务。
3. 具体能不能用上，要看所在城市和个人条件。
```

### 正文结构

正文长度建议：600-900 字。

固定结构：

1. 这件事是什么
2. 为什么现在提
3. 和年轻人有什么关系
4. 可以重点看什么
5. 不要误读

### 正文写法原则

- 用普通话解释政策内容，不直接堆原文。
- 连接就业、租房、教育、医保、消费、城市生活等具体场景。
- 不夸张判断，不做标题党。
- 重点解释用户能怎么查、怎么看、需要留意什么。
- 对容易误读的地方单独说明。

### 观点规则

文章默认中立。

如果原文有观点：

- 标注为“来源观点”。
- 用中立语言总结其主张。
- 不把来源观点包装成平台立场。

如果原文只是政策或通知：

- 不替用户下结论。
- 只解释政策目标、影响范围和可能变化。

可以加入轻量模块：

```text
见闻观察
```

示例：

```text
这类政策真正影响用户体验的地方，往往不在文件标题里，而在地方执行细则和申请门槛里。
```
