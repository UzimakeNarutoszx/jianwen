# 内容资源策略

MVP 采用“轻量可配置来源池”。

来源不完全写死在代码里，而是以白名单方式维护。首版来源池可以先很小，只放适合早间调用和 AI 问答依据的高可信来源；后续再逐步扩展。

每个来源至少需要配置：

- 来源名称
- 来源级别
- 来源链接或域名
- 允许用途：生成主文章 / 辅助参考 / 只展示外链
- 是否允许进入 AI 问答上下文
- 是否需要人工审核

首版原则：

- A 级官方来源可以作为主文章和 AI 问答的核心依据。
- B 级主流媒体来源只作为公共事实参考、延伸阅读和来源入口，不做全文改写，不作为主文章素材池。
- C 级内容默认不进入生产流程，除非已有明确授权。
- 来源池变更需要留下记录，方便追溯某篇内容生成时用了哪些来源规则。

### A 级：适合作为核心内容源

优先使用：

- 中国政府网
- 国家法律法规数据库
- 各部委官网
- 地方政府官网
- 全国人大官网
- 中国政协官网
- 最高法、最高检官网
- 中央和国家机关公开公告、决定、规划、意见、通知

这类内容更适合做政策原文解析、短文章解释和 AI 问答依据。

### B 级：可作为参考来源

包括：

- 新华社 / 新华网
- 人民日报 / 人民网
- 央视新闻 / 央视网
- 光明日报
- 经济日报
- 中国青年报
- 地方党报和主流新闻网站

使用方式：

- 可展示标题、来源、发布时间、原文链接。
- 可提炼公共事实。
- 可作为延伸阅读。
- 不建议全文调用、全文抓取、全文改写后发布。

### C 级：需要授权后再重度使用

包括：

- 媒体全文稿件
- 新闻图片
- 视频
- 图表
- 版面
- 专栏评论
- 深度报道
- 学习强国内的课程、音视频、专题结构和平台内容

原则：

> 可以把央媒作为权威来源，但不要把央媒文章当作免费素材池。
