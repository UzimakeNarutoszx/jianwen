# 来源与依据模块

### 模块目标

让用户知道内容从哪里来，避免“AI 自己说了算”的感觉。

### 政策原文来源

可展示：

- 文件标题
- 发布机构
- 发布时间
- 原文链接
- 关键依据摘要

示例：

```text
国务院办公厅关于进一步做好高校毕业生等青年就业创业工作的通知
发布机构：中国政府网
[查看原文]
```

### 媒体报道来源

对于新华社、人民日报、人民网、央视新闻等媒体内容：

- 只展示标题、媒体名称、发布时间、跳转链接。
- 不在 App 内全文展示。
- 不将媒体文章直接交给 AI 改写后发布。

按钮文案：

```text
查看原文报道
```
