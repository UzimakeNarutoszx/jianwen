# 视觉方向

整体感觉：

- 清爽
- 可信
- 年轻
- 不娱乐化

建议风格：

- 白色或浅灰背景
- 深色正文
- 少量蓝绿色或松石色作为品牌色
- 卡片轻边框
- 避免厚重阴影
- 圆角控制在 8px 左右
- 信息密度适中
- 不用大面积红色政治视觉
- 不做积分、勋章、任务中心
- 可以借鉴游戏化产品的进度反馈和状态表达，但不引入积分、等级、勋章、排行榜或强打卡机制。

### 信息呈现原则

视觉设计的重点不是把内容写得更长，而是把“讲清楚”变成“扫一眼能理解”。页面应优先服务浏览和判断，让用户先看到结论，再决定是否展开细节。

信息组织建议采用三层结构：

1. 第一层：一句话结论
2. 第二层：3 个关键点
3. 第三层：可展开的背景、过程和依据

不要把背景、过程、判断和结论揉在同一段里。公共议题内容尤其需要先给用户方向，再补充必要解释。

不同类型的信息优先用不同视觉形式承载：

- 流程类：流程图
- 对比类：表格或左右对照
- 数据类：柱状图、折线图、饼图
- 结构类：架构图、关系图、模块图
- 时间类：时间轴

每一屏只承担一个主要信息点。标题说结论，图形做支撑，文字只保留必要补充。长解释可以放进悬浮提示、点击展开或详情页，不要压在主界面里。

可以用“关键词 + 图标”替代长句。例如“注册、登录、填写信息、查询结果”这类流程，不需要写成完整说明，可以呈现为：

```text
注册 -> 登录 -> 填写 -> 查询
```

复杂段落优先拆成卡片。每张卡片只放一个标题、一句说明，以及一个数字、图标或状态。涉及数据时，数字和结论要突出显示，解释文字缩小，例如“提升 35%”“减少 2 步”“响应时间 < 1s”。

一句话原则：

```text
把页面从阅读型改成浏览型：先给结论，再让用户选择是否看细节。
```

品牌关键词：

```text
清醒
可信
不端着
有来源
能追问
```
