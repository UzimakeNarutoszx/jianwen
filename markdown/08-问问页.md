# 问问页

### 页面定位

“问问”是统一 AI 对话能力的完整页面，和文章详情页里的“继续问问”共用同一套上下文。

文章里的“继续问问”围绕当前文章展开；底部导航里的“问问”可以承接这段文章上下文继续聊，也可以聊更广泛的政策、新闻和公共议题。

### 页面目标

提供一个类似网页版 AI 的聊天体验，但更聚焦政策、新闻、公共议题和年轻人的现实问题。

### 页面标题

问问见闻

### 副标题

```text
聊政策、新闻和你关心的现实问题
```

### 页面结构

从上到下：

1. 每日推荐问题
2. 当前上下文提示
3. 历史记录 / 最近对话
4. 聊天内容区
5. 底部固定输入框

### 每日推荐问题

每日推荐问题用于降低首次提问门槛。

推荐问题要具体，少用大词，多从用户场景出发。

示例：

```text
最近有哪些政策和年轻人就业有关？
租房补贴一般怎么查？
医保改革会影响报销吗？
AI和未来就业到底有什么关系？
这周有哪些消费补贴值得留意？
```

### 历史记录

历史记录可以按日期分组。

示例：

```text
今天
- 毕业生就业补贴怎么查？
- 保障性住房和公租房有什么区别？

昨天
- 新质生产力是什么意思？
```

未登录状态下：

- 可保留本机临时记录。
- 换设备不同步。
- 引导用户登录以同步历史记录。

登录后：

- 同步 AI 对话记录。
- 支持收藏重要回答。
- 后期可按主题自动归档。

### 当前上下文

当用户从文章详情页进入问问页时，顶部应显示当前对话关联的文章或来源，例如：

```text
正在围绕：刚毕业找工作，最近有哪些政策可能用得上？
来源：人社部 / 中国政府网 / 公开政策文件
```

用户可以选择继续围绕这篇文章追问，也可以清空上下文，开始一个新问题。

空白进入问问页时，不显示文章上下文，只展示每日推荐问题和最近对话。

### 聊天内容区

AI 回答应体现“见闻”的核心气质：

- 清楚。
- 克制。
- 有来源。
- 不端着。
- 不假装确定。

回答可以包含：

- 简短结论
- 背景解释
- 和年轻人的关系
- 可继续追问的问题
- 来源链接

### 底部输入框

输入框占据底部固定区域。

占位文案：

```text
输入你想问的政策或新闻问题
```

辅助按钮：

- 发送按钮
- 语音按钮，后期预留
- 添加链接按钮，后期预留

### 问答口径

可以回答：

- 政策背景解释
- 新闻公开信息总结
- 概念拆解
- 多方观点梳理
- 政策和普通人的关系
- 如何查原文、查本地政策

需要谨慎：

- 无来源的具体数据
- 未证实消息
- 强预测
- 极端立场判断
- 法律、投资、医疗等专业建议

回答策略：

- 普通解释可以直接回答。
- 涉及具体政策、数据、新闻时显示来源。
- 不确定就说明不确定。
- 遇到专业判断时提示用户咨询专业机构或以官方信息为准。

### 对话页重点总结

“问问”页不是普通闲聊机器人，而是“政策和时政陪读器”。它既能承接用户刚读过的文章，也能帮助用户从一个新的现实问题开始问。

它的重点不是让用户一直刷，而是帮用户把一个模糊问题问清楚、把一条公共信息看明白。

设计重点：

1. 推荐问题要像真实年轻人会问的话，不要像政策标题。
2. 历史记录要突出“继续上次的问题”，尤其是从文章追问延伸出的上下文，减少重复输入。
3. 输入框要始终可见，保持 AI 工具的熟悉感。
4. 回答里要区分事实、解释、判断。
5. 涉及政策、数据、新闻时默认展示来源或来源入口。
6. 不让 AI 显得像官方口径复读机，也不让它变成无边界评论工具。
7. 推荐追问要推动用户理解，比如“讲简单点”“和我有关吗”“依据在哪”“还有哪些城市类似”。
