# pages/settings/legal UI 方案

## 页面定位

隐私政策与用户协议页是合规阅读页，应正式、稳定、可读。

## 设计方案

- 顶部加入文档/盾牌图标和更新时间。
- 内容卡按章节展示，标题使用深色，正文行高加大。
- 长文本页面减少装饰，避免影响阅读。
- 可在顶部加入“最后更新”和“适用范围”信息条。
- 暗色模式以低对比深色卡片为主，保证正文不刺眼。

## iconfont 建议

- 搜索词：`legal`、`privacy`、`shield`、`document`、`policy`。
- 推荐新增：`ui-shield.png`、`ui-document.png`、`ui-privacy.png`。

## 验收点

- 长文本不拥挤。
- 更新时间清晰。
- 卡片间距稳定。
