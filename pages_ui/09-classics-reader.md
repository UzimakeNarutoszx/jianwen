# pages/classics/reader UI 方案

## 页面定位

电子书阅读器应保持沉浸、低干扰，视觉可区别于资讯页。

## 设计方案

- 保留纸张阅读风，但提升页边、阴影、装订线细节。
- 顶部栏弱化为半透明纸色，返回按钮换 iconfont。
- 封面页加入书名、作者、来源、装饰线，保持典籍感。
- 正文页控制每屏信息量，避免装饰压缩阅读区域。
- 底部进度条升级为章节感进度，显示页码和当前章节。
- 暗色模式使用深棕黑纸张，不使用纯黑。

## iconfont 建议

- 搜索词：`back`、`book`、`bookmark`、`page`、`progress`。
- 推荐新增：`ui-back.png`、`ui-bookmark.png`、`ui-page.png`。

## 验收点

- 长文在大字号下不溢出。
- swiper 翻页不出现空白或遮挡。
- 顶部和底部控件不干扰阅读。
