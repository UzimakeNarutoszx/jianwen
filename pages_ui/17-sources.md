# pages/settings/sources UI 方案

## 页面定位

内容来源说明页用于建立可信度，应做成“来源透明度说明”页面。

## 设计方案

- 顶部加入来源/认证图标，标题突出“内容来源说明”。
- 每个来源等级做成等级卡：A级官方来源、B级权威媒体等。
- 等级卡使用不同低饱和色条，但主色仍保持青蓝和金色。
- 普通说明段落保持文档式阅读体验。
- 可加入“我们如何使用来源”的流程图式三步说明。

## iconfont 建议

- 搜索词：`source`、`verified`、`official`、`level`、`flow`。
- 推荐新增：`ui-source.png`、`ui-verified.png`、`ui-level.png`、`ui-flow.png`。

## 验收点

- 来源等级一眼能区分。
- 说明文字保持权威感。
- 与 legal 页共享文档阅读风格。
