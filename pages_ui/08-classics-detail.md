# pages/classics/detail UI 方案

## 页面定位

经典文献详情页应像“数字典籍封面页”，兼顾庄重和现代感。

## 设计方案

- 顶部使用典籍封面 hero，封面图、书名、作者、来源形成强视觉。
- “开始阅读”按钮做成主 CTA，配书本/阅读 icon。
- 阅读方式说明改成信息提示卡，减少说明文字压力。
- 目录列表做成章节轴线：序号、章节名、摘要、阅读入口。
- 页面色调可比其他页面更偏纸张米色，但仍保留青蓝主色。

## iconfont 建议

- 搜索词：`book open`、`chapter`、`read`、`source`、`back`。
- 推荐新增：`ui-book-open.png`、`ui-chapter.png`、`ui-read.png`。

## 验收点

- 封面和目录层级清楚。
- 空状态有返回发现页的明确路径。
- 暗色模式保持典籍质感。
