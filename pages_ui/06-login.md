# pages/auth/login UI 方案

## 页面定位

登录注册页是信任建立页面，需要比普通表单更正式、清晰、安全。

## 设计方案

- 背景使用浅色渐变和微光，中心品牌区展示浅色 App 图标。
- 登录/注册/忘记密码用分段控件统一承载，避免页面跳变突兀。
- 表单卡使用玻璃白卡，输入框配 iconfont：用户、手机、锁、验证码。
- 密码显示隐藏改为眼睛图标按钮。
- 协议提示保留但更轻，主按钮保持深青蓝。
- 注册和重置密码时验证码按钮做成右侧独立胶囊。

## iconfont 建议

- 搜索词：`phone`、`lock`、`eye`、`sms`、`shield`、`login`。
- 推荐新增：`ui-phone.png`、`ui-lock.png`、`ui-eye.png`、`ui-sms.png`。

## 验收点

- 手机号/密码/验证码输入区域对齐稳定。
- 错误提示不破坏布局。
- 暗色模式下输入框边界清楚。
