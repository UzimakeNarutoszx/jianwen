# 见闻全局 UI 统一方案

## 统一方向

全站统一沿用今日页已建立的方向：高级政经杂志风、轻玻璃拟态、浅色为主、少量金色点缀。视觉目标是“可信、精致、有信息密度”，不是娱乐化、纯赛博或大红宣传风。

## 视觉基准

- 背景：浅米白到浅青灰渐变，局部使用低透明金色和蓝绿色光感。
- 主色：深青蓝 `#1F5F7A`，用于主操作、重点标签、阅读进度。
- 点缀：低饱和金色 `#D4AA4E`，用于强调、编号、关键状态。
- 文本：标题深墨色，正文蓝灰，辅助信息低对比灰。
- 卡片：28rpx 左右圆角、半透明白、轻边框、柔和阴影。
- 图片：重要内容优先用真实主题图，叠深浅渐变保证文字可读。
- 暗色：深蓝黑背景、玻璃卡片、低亮度金色和浅蓝强调。

## iconfont 使用规则

- 可从 iconfont 搜索并下载统一线性/双色图标，优先 PNG 或 SVG 后转 PNG，放入 `frontend/static/icons/`。
- 图标风格统一：线性、圆角、2px 左右笔画、避免卡通和强拟物。
- 命名建议：`ui-calendar.png`、`ui-book.png`、`ui-search.png`、`ui-user.png`、`ui-source.png`。
- 不把 iconfont 账号密码写入代码、Markdown 或仓库配置。

## 组件统一

- 顶部区域：统一为 glass topbar 或 mini hero，包含标题、副标题和必要状态。
- 列表卡：图片型卡片使用编号、主题标签、来源/时间 metadata。
- 表单页：使用居中品牌区 + 分段控件 + 大输入卡片。
- 空状态：使用图标、短标题、说明、一个主按钮。
- 返回按钮：替换文本 `‹` 为 iconfont 返回图标，统一 56rpx 点击区。

## 验收标准

- 每页浅色模式和暗色模式都可读。
- 大字号不挤压按钮和卡片。
- Tab 页第一屏有明确视觉记忆点。
- 非 Tab 页返回、主操作、空状态一致。
- 不引入新 JS/CSS 库，优先修改页面 scoped style 和已有静态资源。
