# pages/search/search UI 方案

## 页面定位

搜索页应像“信息检索台”，重点是快速输入、结果可扫、无结果有引导。

## 设计方案

- 顶部返回按钮和搜索框合并成搜索工具栏。
- 搜索框使用玻璃白大输入，左侧 iconfont 放大镜，右侧可预留清除按钮。
- 未输入时展示推荐热词和热门主题。
- 搜索结果用紧凑文章卡，关键词可做高亮样式。
- 空状态使用搜索图标、建议关键词、返回发现页按钮。

## iconfont 建议

- 搜索词：`search`、`clear`、`hot`、`empty`、`back`。
- 推荐新增：`ui-search.png`、`ui-close.png`、`ui-hot.png`、`ui-empty-search.png`。

## 验收点

- 输入聚焦后首屏仍可用。
- 结果数量变化不造成明显跳动。
- 无结果状态不显得像错误。
