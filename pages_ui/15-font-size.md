# pages/settings/font-size UI 方案

## 页面定位

字号页是阅读舒适度设置，应直观、可预览、少干扰。

## 设计方案

- 顶部保留简洁标题，加入阅读舒适度图标。
- 三个字号选项做成纵向大卡，每项展示真实字号预览。
- 选中态使用深青蓝边框、浅青背景、对勾图标。
- 预览卡升级为“政策摘录”小样，随字号实时变化。
- 页面不需要复杂装饰，重点是清晰和可操作。

## iconfont 建议

- 搜索词：`font size`、`text`、`check`、`reading`。
- 推荐新增：`ui-text-size.png`、`ui-check.png`、`ui-reading.png`。

## 验收点

- 三种字号差异肉眼明显。
- 大字号下选项说明不溢出。
- 返回 profile 后设置生效。
