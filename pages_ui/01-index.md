# pages/index/index UI 方案

## 页面定位

启动中转页，用户停留时间极短，但仍应保持品牌一致性，避免白屏式跳转。

## 设计方案

- 背景使用与今日页一致的浅色高级渐变。
- 中央展示浅色 App 图标和“见闻”品牌字样。
- 文案改为“正在整理今日简报”，弱化技术跳转感。
- 加入小型加载光环或三段点状进度，不引入复杂动画。

## iconfont 建议

- 搜索词：`loading`、`compass`、`book open`。
- 可选：用 `ui-compass.png` 做品牌辅助图标。

## 验收点

- 跳转失败时页面仍有品牌完整感。
- 暗色模式下背景和图标不刺眼。
