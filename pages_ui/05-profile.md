# pages/profile/profile UI 方案

## 页面定位

我的页是个人资产和设置入口，应做成“个人信息控制台”。

## 设计方案

- 顶部账号卡升级为玻璃身份卡，头像、昵称、登录状态、同步状态同屏呈现。
- 功能区保持一行图标式入口，但换成更大的 iconfont 双色图标。
- 关注主题改为可视化兴趣云，选中状态使用深青蓝 + 金色边缘。
- 设置区做成分组列表：阅读、AI、合规、账号。
- 编辑资料卡采用表单浮层感，按钮和输入框统一高端玻璃风。

## iconfont 建议

- 搜索词：`favorite`、`history`、`chat record`、`settings`、`user`、`sync`。
- 推荐新增：`ui-favorite.png`、`ui-history.png`、`ui-chat-record.png`、`ui-settings.png`。

## 验收点

- 未登录和已登录两种状态都高级。
- 功能入口一眼可扫。
- 设置项不显得杂乱。
