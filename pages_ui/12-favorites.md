# pages/profile/favorites UI 方案

## 页面定位

收藏页是用户的知识资产库，应比普通列表更有“资料夹”感。

## 设计方案

- 顶部增加资料夹 hero：标题、收藏数量、最近同步状态。
- 收藏列表卡加入收藏星标、主题、阅读时间、来源。
- 可增加轻量筛选：全部、政策、民生、科技。
- 空状态使用收藏图标，主按钮“去今日看看”。
- 与历史页共用一套资料列表组件风格。

## iconfont 建议

- 搜索词：`favorite`、`folder`、`star`、`article`、`empty`。
- 推荐新增：`ui-folder-star.png`、`ui-star-filled.png`、`ui-empty-favorite.png`。

## 验收点

- 未登录/无收藏状态表达清楚。
- 列表信息密度高但可扫。
- 与历史页视觉一致。
