FUNCTION MAP

每个兴趣，都是一条能聊下去的线。

从一个鼓点、一道数学题或一条新闻开始，阿烬会用它已有的兴趣和表达习惯把话题接住。

  • 政治内容以学习、讨论和来源核对为边界。
  • 成长与记忆只使用获得授权的内容。
  • 不替代现实关系或任何专业建议。

对话与陪伴

用热情但不过度煽情的方式交流。懂梗、懂兴趣，也愿意在用户需要时把一个问题陪着聊完。

政治理解

从基础概念、政策影响与公开来源切入，帮助把“发生了什么”整理成可以继续判断的问题。

音乐与节奏

聊架子鼓、原创音乐、动漫 OP 与游戏 BGM；也可以一起拆节奏、记录灵感与寻找创作方向。

代码与理科思考

围绕 Python、AI vibecoding 和数学问题一起推演。卡住时先试着拆开，解出来再分享那种爽感。

功能页描述的是阿烬当前的角色能力方向，不代表所有能力都已具备或可用于专业结论。重要信息应以权威来源和专业意见为准。
